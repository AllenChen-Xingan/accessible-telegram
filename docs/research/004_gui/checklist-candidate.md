> **判法**（对应 `CLAUDE.md` 第三节三层验证）：
> - **机-树（mac）** = 开真窗口导出 **macOS 层**（逐个问 AX 属性：角色、子角色、名称、值、动作、frame、标识）后脚本判。**VoiceOver 读的是这一层**；未注明层的机-树条目都按这一层判
> - **机-树（gpui）** = 导出 **GPUI 层**（`Window::debug_a11y_tree_json()`）后脚本判。只用于 macOS 层拿不到的属性：位置 / 总数、busy、Live 等到了 macOS 层会丢（`findings-gpui.md` 结论第 5 条与第 2 节表、001 第二节第 3 小节）
> - **机-测** = `cargo test` 单元 / 快照测试，不开窗口 · **机-读** = 读代码或配置、可写成脚本的规则判（grep、正本比对、clippy）
> - **判据** = AI 按写下的判据审代码或文本（代码审查类），不能写成脚本 · **人** = 开着 VoiceOver 或对应辅助技术亲自试（验证红线）· **人 + agent** = 让 agent 只读树执行任务，人看结果判过不过
> - **需补丁** = GPUI / AccessKit 现在做不到；人定自己打补丁再回上游（013 B19-1），方案归 ggpui（核 GPUI 的窗口）。补丁落地前此条记「不过」，不降标准。**可能需补丁** = 先按普通条目判，判不过且查明是上游缺口再转「需补丁」
> - **〔阈值待定〕/〔范围待定〕/〔清单待定〕** = 数值或范围待 gssot 在 `specs/gui/` 定；定之前此条不判
> - **〔待人试听，可改〕** = 照现行人定判（照常判过 / 不过）；人试听后改了，条目跟着改
> - **实验候选** = 不需补丁、要先做实验验证可行；实验做完前此条记「不过」（同需补丁，不降标准）
> - 括号里的 **P1、P2、P15** 等是 `specs/gui/upstream-patches.md` 的**补丁编号**，不是评审严重等级
> - **直发** 两个意思别混：「直发公告」= 应用直接请 macOS 念一句（播报出路，001 第二节第 2 小节）；「直发模式」= 发消息免确认的启动参数（001 第七节第 11 条）
> - 播报的路由（哪类事件、什么应用状态、走哪条出路、几档）以 `specs/gui/announce.md` 第三节路由表为正本，本组条目与它冲突时以它为准
> - **应用状态**：以 `specs/gui/announce.md` 为准（被挡 = 本应用在前台但窗口被盖住或不是 key 窗口；后台 = 本应用不在前台）
> - 组合判法（如「判据 + 人」「机-树 + 机-测」）= **都过才算过**；标「建议项」的不过不影响整体
> - **工具现状**：macOS 层导出与 AppKit 真按键自测脚本沿用 exp003 的做法（`docs/experiments/exp003-list-nav/` 的 `src/ax.rs` 与 `selftest-tab`），正式的 `TreeDump`（001 第二节第 3 小节）待 GUI 阶段建；「夹具」= `atg-gui --fixture` 喂的编造数据（001 同节）
> **术语**：读法 = 一个元素被读屏念出的那句话，只由 `atg-core` 的 `speech` 模块生成；读法快照 = 用 insta 把夹具消息的读法存成期望文件，改了就对比差异（001 第三节）· brief / detail = 读法的简短 / 详情两层 · 档 = 播报档位（最低 / 低 / 高），落到实际数值看出路——直发公告：最低 = 10、低 = 10、高 = 90；Live 节点：低 = Polite 50、高 = Assertive 90，不用于最低档 · Live 节点 = 在一个不可见的 AccessKit 节点上设 live 属性，由 accesskit_macos 翻成系统公告（所以它和直发公告最终都是 `AnnouncementRequested`，区别是走不走界面树）（`specs/gui/announce.md`「档位怎么落到值」；系统取值 `AXC.h:624-626`）· 转子 = VoiceOver 里 VO-U 打开、按类别（标题、链接、自定义类）跳着浏览的菜单· VO 键 = Ctrl-Opt · 快速导航 = VoiceOver 开着时吃方向键 / 单字母的模式 · active-descendant = 焦点留在列表容器、用指针标当前项 · press 动作 = 元素可被「按下」的无障碍动作 · frame = 元素在屏幕上的矩形。详见 `findings-a11y.md` 文件头
