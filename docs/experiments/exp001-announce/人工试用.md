# 人工试用 · exp001 播报

准备：终端里在项目根目录运行一次 `docs/experiments/exp001-announce/run.sh`，弹出窗口「exp001 播报实验」。打开 VoiceOver（Command+F5）。
按键都是单个字母，不带修饰键。若字母被 VoiceOver 吃掉，先同时按左右方向键关掉快速浏览。

每步一行：按什么 → 应该听到什么。听到的不一样就记下来。

1. 按 Command+Tab 切到窗口 → 听到窗口名「exp001 播报实验」
2. 按 n → 听到「新消息，张三：晚上一起吃饭吗」；焦点不动（再按 VO+F3 读当前项，还是原来的位置）
3. 按 n → 听到「新消息，李四：文件我发你邮箱了」
4. 按 r → 礼貌式、不绕：**预计听不到**（同一句话）。听到了也记下
5. 按 w → 听到「礼貌式，换节点」
6. 按 r → 听到刚才那句（换节点绕法生效）
7. 按 w → 听到「礼貌式，零宽字符」；按 r → 听到刚才那句，留意是否多读了怪声音
8. 按 w → 听到「礼貌式，不绕」（回到不绕）
9. 打断测试（礼貌式）：用 VO+方向键移到第三条「王五：这是一条很长的消息……」，按 l，再马上按 VO+A 让它朗读。三秒后来消息 → 记下：**等读完才播 / 插进来播 / 没播**
10. 按 p → 听到「打断式，不绕」
11. 重复第 9 步（打断式）→ 记下：**掐断长句立即播 / 等读完 / 没播**
12. 按 f → 听到「兜底直发：这句话不经过 GPUI」
13. 再按 f → 同一句应再次听到（兜底不受「值没变」限制）

试完把第 4、6、7、9、11、13 步听到的写回 README 的「结论」一节（或口头告诉大总管）。
