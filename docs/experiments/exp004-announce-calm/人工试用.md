# 人工试用 · exp004 新消息提示不打断朗读

准备：项目根目录运行 `docs/experiments/exp004-announce-calm/run.sh`，弹出窗口「exp004 新消息提示」。开 VoiceOver（Command+F5）。
按键都不带修饰键。字母、数字被 VoiceOver 吃掉时，先同时按左右方向键关掉快速浏览。

**每种模式都做同一个动作（下称「长句测试」）**：按 ↑ 或 ↓ 选到第三条「王五：这是一条很长的消息……」，听它开始读，**马上按 l**（三秒后来一条新消息），然后手离开键盘，听到读完。
每步记一个词：**被打断 / 没被打断 / 听不到**。另有要听的写在箭头后。

1. 按 1 → 听到「模式 1，礼貌式」→ 长句测试 → 记（对照，预计被打断）
2. 按 2 → 听到「模式 2，低优先级」→ 长句测试 → 记；没被打断的话，读完后有没有补说「新消息」
3. 按 3 → 听到「模式 3，提示音」→ 长句测试 → 记；有没有听到「啵」一声，声音会不会盖住朗读
4. 接上一步按 m → 听到「新消息，赵六……」之类
5. 按 4 → 听到「模式 4，静候再说」→ 长句测试 → 记；读完后约三秒有没有听到「新消息，……」
6. 按 5 → 听到「模式 5，估算朗读时长再说」→ 长句测试 → 记；读完后多久听到「新消息，……」（太早 / 刚好 / 太晚）
7. 按 6 → 听到「模式 6，写进名称」→ 长句测试 → 记；然后按 VO+F2 读窗口标题 → 应听到「……，1 条新消息，按 M 收听」
8. 按 7 → 听到「模式 7，写进提示语」→ 长句测试 → 记；然后按 ↓ 再按 ↑ 回到长句 → 读完长句停顿后应听到「1 条新消息，按 M 收听」
9. 连发测试：按 4，选到长句，按 k（三秒后起每秒来 1 条，共 3 条），手离开 → 读完后应只听到一句「3 条新消息，最新：……」
10. 浏览中测试：按 4，按 k，然后每秒按一次 ↓ 一直按到第 9 条左右 → 按键期间应听不到提示，停手三秒后听到汇总
11. 后台测试：按 2，按 l，马上按 Command+Tab 切到别的应用 → 三秒后记：**听到「新消息」/ 没听到**；再按 3、l、切走，记有没有听到「啵」

试完把每步那个词告诉大总管就行，第 2、3、5、6 步多一句听感更好。
