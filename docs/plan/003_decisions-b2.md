## 读法

**原则（人定）**：读出声的始终是 VoiceOver，本项目只决定每项的名称文字。**名称只放主要内容：谁发的、说了什么、几点**；回复谁、转发自谁、已编辑、表情回应、日期等一律进「详情」，人按详情键展开。**不截断、不设时长上限**——听够了人自己用 Control 打断或按 ↓ 走。

| # | 事项 | 结果 |
|---|---|---|
| R1 | 隐藏内容（剧透） | 读「隐藏内容，按 D 展开」（人选） |
| R2 | 会话项最后一条截多长 | **不截断**（按原则）；`specs/tasks.md` T02「约 3 秒」判据删去 |
| R3 | 时间 | 名称里只读钟点；日期进详情（按原则） |
| R4 | 回复 / 转发 | 不进名称，进详情（按原则） |
| R5 | 已编辑 / 表情回应 | 不进名称，进详情（按原则） |
| R6 | 相册 | 每张一项（按建议；GUI 阶段再看） |
| R7 | 撤回占位 | 「林小雨撤回了一条消息，19:36」（按建议，主要内容同形） |
