name: single-write-gate
description: 「某类数据不许存 / 不许漏」这种规则（受限原文、密钥、隐私字段），要收拢成唯一写入口 + 穷举所有写入路径的测试 + 变异检验；只管这类不变量，不管普通业务逻辑
type: feedback
---

**为什么**：#15 里「受限消息不留原文」逐个入口补了四轮（第八至第十一轮），codex 每轮都从新入口找到泄漏（引用、淘汰后补丁、墓碑、登记表 Debug）。改成「写消息内容只能经 `store/table.rs` 的私有入口，先查受限再落盘」+ 一个喂暗号走遍全部写入路径的测试后才收敛（`docs/reviews/005_model-reducer-codex.md`）。

**怎么用**：
- 遇到「X 绝不能出现在 Y 里」的规则，第一版就做成唯一入口（用模块私有 / 类型让别处绕不过），别等评审一处处补
- 配一个穷举测试：把带暗号的 X 从每条写入路径喂进去，断言整个状态（含 `{:?}`）里找不到暗号；并断言暗号确实进过系统（防空转）
- 做一次变异检验：临时拿掉入口里的清理，测试必须失败
