## 判法（同候选）

- **机-树（mac）** = 开真窗口导出 macOS 层后脚本判（VoiceOver 读这一层；未注明层的机-树都按这一层；格式与各条查哪一项见 `a11y-tree.md` 第四节）· **机-树（gpui）** = 导出 GPUI 层后判，只用于 macOS 层拿不到的属性（位置 / 总数、busy、Live、展开、active descendant）
- **机-测** = `cargo test`，不开窗口 · **机-读** = 读代码或表、可写成脚本 · **判据** = AI 按写下的判据审，写不成脚本 · **人** = 开着 VoiceOver 或对应辅助技术亲自试（验证红线）· **人 + agent** = agent 只读树执行任务、人看结果
- **需补丁** = 要 `upstream-patches.md` 里某个补丁（P 号）；落地前记「不过」，不降标准 · 组合判法都过才算过；「建议项」不过不影响整体
- **档位**（高档 / 低档 / 最低）一律照 `announce.md` 第三节「档位怎么落到值」：高 = 直发 90 / Live Assertive；低 = 直发 10 / Live Polite（50）；最低 = 只直发 10。不用中档
